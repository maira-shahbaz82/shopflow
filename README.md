# ShopFlow - Week 1 Review (Day 7)

**What the app does today:**
ShopFlow is a console-based product management system. It can add new products, view all products in a clean table, and search by product code. The app is now fully crash-proof - tested with bcasd, abc, 1,200.

**How to run it:**
Open in IntelliJ and Run Main.java from com.shopflow package.

**Features Implemented:**
- Day 5: Refactoring - Created reusable methods printHeader() and printRow(Product p) - DRY Principle.
- Day 6: Bug Fixing - Made crash-proof using try-catch. Added 3 helper methods: readNonEmptyString(), readPositivePrice(), readNonNegativeStock() with while(true) loop. Fixed NumberFormatException and duplicate code check.

**What is not built yet:**
- No database/file saving (uses ArrayList)
- No Update/Delete product
